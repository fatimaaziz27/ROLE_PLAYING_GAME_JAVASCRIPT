# Role Playing Game

A browser-based **Role-Playing Game (RPG)** built using **HTML, CSS, and JavaScript**. This project was created to practice JavaScript fundamentals, DOM manipulation, game logic, variables, arrays, functions, and interactive user interfaces.

## Overview

The game allows the player to explore a simple RPG experience where they can fight monsters, use different weapons, gain experience, manage health and gold, and progress through the game.

The project focuses on implementing game mechanics using vanilla JavaScript without external frameworks.

## Features

* Interactive RPG gameplay
* Monster battles
* Player health system
* Experience (XP) system
* Gold system
* Weapon system
* Inventory management
* Different weapons
* Combat actions
* Monster health tracking

* Dynamic content updates using JavaScript

## Game Mechanics

### Player

The player has several properties that change during gameplay:

* **Health** — determines whether the player is still alive.
* **XP** — increases as the player progresses.
* **Gold** — used as part of the game's progression and economy.
* **Weapon** — determines the player's available attack options.
* **Inventory** — stores the player's items.

### Combat

Players can fight different monsters using their available weapons.

During combat:

1. The player selects an attack.
2. Damage is calculated.
3. The monster's health is reduced.
4. The monster can attack the player.
5. The player continues fighting until the monster is defeated or the player loses.

### Weapons

The game includes a weapon and inventory system that allows the player to manage available weapons during gameplay.
